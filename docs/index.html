AI 人才地图扩展

用于扩展、更新和核验 AI 人才地图。它把社交媒体、社群、论文、开源项目、公司官网和会议活动中的线索整理为可追溯的人物与渠道数据。

查看完整 SKILL.md · 查看数据契约

适用场景

人才拓展

扩展 Kimi、Seed、可灵、MiniMax、阶跃星辰、AI Infra 和主流实验室人员。

社媒与社群

覆盖 LinkedIn、X、小红书、微信公众号、微信群、飞书群、知识星球、Slack、Discord 和 GitHub Discussions。

关系溯源

记录师承、共同作者、同团队、共同创业、组织调动和开源合作，并保留证据强度。

地图维护

更新人物与渠道时，保留原有标注、备注、脑图位置、折叠状态和 localStorage。

证据等级

强证据官方团队页、本人当前主页、本人 LinkedIn、一手公告、带当前资料交叉核验的技术报告。

中证据权威采访、会议讲者页、维护者历史、两家独立来源对同一人物和职责的确认。

发现线索搜索摘要、转载、匿名社群发言、评论、无来源截图、单独的模型上传或论文署名。

发现线索不会直接升级为确定任职，会使用“待核验”“作者池”“公开关联”等标签，并记录下一步核验动作。

更新规则

  1. 先读取现有人才地图结构、稳定标注键和本地存储机制。
  2. 多渠道搜索，并区分当前任职、历史经历、技术贡献和社群发现。
  3. 检查中英文名、别名和组织变体，避免重复人物。
  4. 保留来源 URL、证据强度、更新批次和待核验动作。
  5. 只追加或更新人物、渠道和关系数据，不覆盖用户标注与备注。

使用方式

Use $ai-talent-map-expander to expand the AI talent map with current, source-verified people while preserving annotations and local storage.
