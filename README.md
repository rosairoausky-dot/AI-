# AI Talent Map Expander

这是一个用于扩展和维护 AI 人才地图的 Codex skill。

## 浏览器访问

启用 GitHub Pages 后，可以直接打开：

https://rosairoausky-dot.github.io/AI-/

人才地图页面：

https://rosairoausky-dot.github.io/AI-/talent-map/

页面源码位于 `docs/index.html`，人才地图源码位于 `docs/talent-map/index.html`。推送到 `main` 后，GitHub Actions 会自动发布。原始 skill 文件仍保留在 `SKILL.md`。

## 使用

```text
Use $ai-talent-map-expander to expand the AI talent map with current, source-verified people while preserving annotations and local storage.
```
